## Sobre o Projeto

Uma página responsiva que apresenta o catálogo e o destaque para o novo episódio da série **Cyber City: 2077**, simulando a experiência de um usuário ao navegar por um serviço de vídeo.

## Ferramentas utilizadas

* **HTML5**
* **CSS3**

## Como visualizar?

1. Faça o download ou clone este repositório.
2. Abra o arquivo `index.html` diretamente no seu navegador.
